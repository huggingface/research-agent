# OKF research report example

This is a deterministic example of the private OKF v0.2 projection produced by
`research/okf_compiler.py`.

- [`report.md`](report.md) is the canonical report input.
- [`evidence.json`](evidence.json) is the optional structured source handoff.
- [`bundle/index.md`](bundle/index.md) is the OKF bundle entry point.
- [`bundle/reports/brief.md`](bundle/reports/brief.md) is the draft `Research Report` concept.
- [`bundle/references/evidence.md`](bundle/references/evidence.md) is the evidence register.

The report concept contains 2 sources and
2 resolved source IDs. Generated reports remain
`status: draft` and unverified until a separate authenticated review occurs.
